# ГТО: учёт результатов (ступени V–IX)

Веб-приложение регионального оператора ВФСК ГТО в Сахалинской области — «Спартак». В нём хранятся результаты сдачи нормативов ГТО по студентам с привязкой к институту и группе. По официальным нормативам с gto.ru приложение само считает знак отличия.

## Роли

| Роль | Что может |
|---|---|
| **Администратор** | всё, что «Ввод результатов», плюс заводит пользователей, выдаёт пароли, блокирует |
| **Ввод результатов** | добавляет и импортирует студентов, вносит, меняет и удаляет результаты |
| **Просмотр** (учителя физкультуры) | ищет студентов, смотрит результаты и даты, выгружает CSV, скачивает шаблон списка |

Каждый входит по своему логину и паролю. Права проверяет сервер, а не только интерфейс.

**Персональные данные.** Роль «Просмотр» видит только фамилию и первую букву имени («Иванов П.»). Отчество, дату рождения и УИН сервер ей вообще не отдаёт, и в выгрузку CSV они тоже не попадают. Администратор и «Ввод результатов» видят всё.

## Что умеет

- Таблица: ФИО, институт, группа, ступень, знак, затем результаты по каждому испытанию. Цвет ячейки показывает уровень: золото, серебро, бронза или «не выполнено».
- Мгновенный поиск по ФИО и фильтры по институту, группе, ступени, полу и полученному знаку.
- Карточка студента со всеми испытаниями ступени. Для каждого результата видны дата испытания и кто и когда его внёс, а также каких обязательных испытаний не хватает до знака.
- Ввод результата в формате «12:20» или «8,4» с подсказкой, на какой знак он тянет.
- У каждого студента есть **УИН ГТО** (формат `23-65-0012345`, уникальный) и **дата рождения**. Ступень по умолчанию определяется по возрасту.
- **Загрузка списка.** Физрук скачивает Excel-шаблон (кнопка «Шаблон списка»), заполняет и передаёт администратору. Администратор загружает файл .xlsx или .csv (можно и вставить строки из Excel) и видит предпросмотр с ошибками по строкам. Студенты, которые уже есть в базе (совпал УИН или ФИО + дата рождения), обновляются, остальные добавляются, так что повторная загрузка ничего не задваивает.
- Экспорт всей таблицы в CSV для Excel.
- Журнал всех изменений (таблица `audit` в базе).

### Как считается знак

Нормативы взяты с gto.ru для ступеней V–IX, отдельно для юношей и девушек (`public/norms.js`).

Знак уровня N дают, если выполнены все четыре обязательные категории (скорость, выносливость, гибкость, сила) не ниже N и всего категорий на уровне N набирается 5 для бронзы и серебра или 6 для золота. Из каждой категории засчитывается лучшее испытание.

## Установка на сервер (одной командой)

Подходит Ubuntu 22.04 или 24.04, в том числе сервер, где уже работают другие сайты (например, `reg.fla65.ru`). Скрипт ставит Node.js 22 отдельно в `/opt/gto/node`, поэтому системный Node и чужие сайты в nginx не трогает.

1. В DNS добавьте запись **A `gto` → IP сервера** и подождите 15–60 минут.
2. Зайдите на сервер по SSH и выполните:

```bash
apt-get update && apt-get install -y git   # на minimized-Ubuntu git нет
git clone -b claude/greeting-d2g8ji https://github.com/AnVr25/Claude.git /tmp/gto-src
sudo bash /tmp/gto-src/gto/deploy/install.sh gto.fla65.ru ваш@email.ru
```

Скрипт:
- запустит приложение как сервис `gto`;
- добавит в nginx сайт `gto.fla65.ru` и получит HTTPS-сертификат;
- включит ежедневную копию базы в `/var/backups/gto`;
- **напечатает пароль администратора**.

Обновление кода — те же две команды (сначала `rm -rf /tmp/gto-src`). База при обновлении сохраняется.

Пользователи из консоли:

```bash
sudo bash /opt/gto/app/deploy/gto-user.sh list-users
sudo bash /opt/gto/app/deploy/gto-user.sh reset-password admin
```

## Ручной запуск (для разработки)

```bash
cd gto
node --no-warnings cli.js add-user admin admin "Ваше имя"
PORT=3000 npm start
```

### Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | порт |
| `HOST` | `127.0.0.1` | адрес; оставьте так, если впереди стоит nginx |
| `GTO_DB` | `./data/gto.sqlite` | файл базы данных |
| `GTO_SECURE_COOKIE` | — | `1`, когда сайт работает по HTTPS (обязательно в боевом режиме) |
| `GTO_TRUST_PROXY` | — | `1` за nginx: брать адрес посетителя из `X-Real-IP` (для защиты от подбора пароля) |

### Поддомен gto.fla65.ru через nginx

```nginx
server {
    server_name gto.fla65.ru;
    listen 443 ssl;  # сертификат — например, certbot --nginx
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
    }
}
```

Автозапуск через systemd (`/etc/systemd/system/gto.service`):

```ini
[Unit]
Description=GTO results
After=network.target

[Service]
WorkingDirectory=/opt/gto
ExecStart=/usr/bin/node --no-warnings server.js
Environment=PORT=3000 GTO_SECURE_COOKIE=1
Restart=always
User=gto

[Install]
WantedBy=multi-user.target
```

### Резервные копии

Все данные лежат в одном файле `data/gto.sqlite`. Копировать его можно на лету:

```bash
sqlite3 data/gto.sqlite ".backup '/backup/gto-$(date +%F).sqlite'"
```
