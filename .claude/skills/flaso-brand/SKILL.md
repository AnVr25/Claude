# Фирменный стиль ФЛАСО / SakhStart

Проекты: `timing-hub/` (хронометраж SakhStart, reg.fla65.ru) и `gto/` (результаты ГТО, региональный оператор «Спартак»).
Образец живого стиля — сайт fla65.ru: тёмно-синий фон, красные дорожки-дуги, узкий Oswald.

## Цвета
| Токен | Цвет | Где |
|---|---|---|
| `--night` | `#0B1D37` | шапки, экран гонки, табло, судейский телефон |
| `--night-2` / `--night-line` / `--night-muted` | `#13284A` / `#2C4166` / `#9FB0C8` | панели, линии и подписи на тёмном |
| `--track` | `#E71E25` | красный дорожки: главное действие, «идёт», ошибки, 3‑px линия под шапкой |
| `--start` | `#F3481D` | оранжевый SakhStart (из логотипа): внимание, номера участников на тёмном |
| `--ok` | `#17905A` | готово, на связи, подтверждено |
| `--ice` / `--panel` / `--ink` / `--muted` / `--line` | `#F2F5F9` / `#FFF` / `#101B33` / `#5E6B80` / `#D9E0EA` | светлые страницы |

Не вводи новые акценты. Красный — только для главного действия на экране и для состояний «идёт/ошибка». Предупреждения — оранжевым.
Тёмная тема — через `@media (prefers-color-scheme:dark)`, токены переопределены в `brand.css`.

## Шрифты
- **Oswald** (400–700) — заголовки, этапы, крупные цифры: время, номера, места. Цифры — `font-variant-numeric: tabular-nums`, чтобы часы не прыгали.
- **PT Sans** (400/700, italic) — основной текст, поля, кнопки.
- Файлы лежат на сервере (`timing-hub/hub/assets/*.woff2`, подключены в `brand.css`) — без интернета на стадионе всё работает. Внешние CDN для шрифтов в timing-hub не использовать.
- Шрифт Nominee из исходников логотипа — коммерческий, в репозиторий (он публичный) не класть; логотипы уже в кривых.

## Логотипы
Порядок, когда знаков несколько: **Сахалин → ФЛАСО → SakhStart** (слева направо). Между партнёрами и SakhStart допустима тонкая вертикальная черта.

`timing-hub/hub/assets/` (отдаются на `/assets/…`, в публичной форме — `/r/assets/…`):
- `sakhalin-light.png` — Сахалин, белый, для тёмного фона; `sakhalin-dark.png` — для светлого.
- `flaso-dark.png` — ФЛАСО для тёмного фона (белый текст), `flaso-light.png` — для светлого; `flaso-mark*.png` — только знак (иконка, favicon).
- `sakhstart-dark.svg` — белое SAKH + оранжевое START, для тёмного; `sakhstart.svg` — чёрное + оранжевое, для светлого; `sakhstart-white/-black/-orange.svg` — одноцветные (чёрный — для печати).
- Пропорции SakhStart ≈ 3,18 : 1. Не перекрашивать, не искажать, не добавлять тени.
На узких экранах оставляй SakhStart, партнёрские знаки убирай вниз (в подвал) или скрывай.

## Компоненты (timing-hub)
- Общий файл `timing-hub/hub/assets/brand.css`: `@font-face`, токены, `.logos`. Каждая страница подключает его до своего `<style>`.
- Шапка: тёмно-синяя, снизу 3 px `--track`.
- Кнопки: `primary` — красная заливка, одна на экран; остальные — белые с серой рамкой; опасные (сброс, удаление) — красный текст и всегда `confirm()`, прятать в меню «Ещё».
- Таблицы: заголовки Oswald 13 px серым, строки с тонкой линией; места 1–3 — `--gold/--silver/--bronze`.
- Скругление `--r: 6px` везде одинаковое. Фокус — видимая рамка `outline: 3px solid #E71E2566`.
- Анимации — только по делу (пульс «идёт», вспышка новой отметки) и с `prefers-reduced-motion`.

## Тексты
- Русский, обычный регистр (не КАПСОМ), глаголы действия: «Подтвердить», «Сформировать забеги», «Протокол для печати».
- Одно действие — одно название по всему интерфейсу.
- Ошибки — что случилось и что сделать, без извинений. Пустые состояния — подсказка, с чего начать.
- Порядок работы со стартом в хронометраже: Подготовка → Регистрация → Чипы → Старт и финиш → Результаты → Документы.

## Проверка перед коммитом
1. Запусти страницу локально и сними скриншоты Playwright: 1440 px, 390 px (телефон), тёмная тема.
2. Нет горизонтальной прокрутки на 360–390 px, нет ошибок в консоли, все `/assets/…` загрузились.
3. Для timing-hub: `python3 timing-hub/tools/selftest.py` — все проверки зелёные; при изменении — поднять `VERSION` в `hub.py`.
