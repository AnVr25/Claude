Ридеры

Сервер проверит адреса от .1 до .254 в сети ящика (через VPN) и покажет, где отвечает ридер. Занимает несколько секунд. Ящик должен быть включён и на связи.

Сервер сам подключается к ридеру через VPN и переподключается при обрывах. За каждым ридером закрепляется свой постоянный порт для Wiclax — его видно в таблице. Точку («Цель») и дублирующую линию задаёте в Wiclax.

РидерАдресВ Wiclax («Общий», 10.66.0.1)Где стоитСвязьОтметокЧасы ридера

«Часы ридера» — насколько время в отметке отличается от времени сервера. Перед стартом проверяйте тестовым чипом: больше ±2 с — синхронизируйте часы ридера.

Как подключать Wiclax. Один ридер на финише — одно устройство «Общий»: 10.66.0.1, порт 9854 (все отметки сразу).
Несколько ридеров (отсечки, дублирующий финиш) — в Wiclax по устройству «Общий» на каждый ридер, порт ридера из таблицы выше. «Цель» и «Бэкап линию» выставляете в Wiclax. Шаблон устройств сохраняется один раз, перед гонкой меняете только «Цель».
Дополнительно: порты по точкам (старый способ)
Порт 9855–9860 отдаёт отметки всех ридеров с указанной подписью «Где стоит».

Забеги «»

    

      
Забег = группа с общим стартом. У каждого забега своя категория и дистанция — по ним строится протокол: место в забеге и общее место среди всех забегов той же категории и дистанции. Если старт один на всех — забеги не нужны.

Участники

    

      
Перетащите сюда файл CSV или Excel со стартовым списком — или вставьте строки ниже

      
Порядок колонок: номер;чип;забег;ФИО;год;команда;категория — лишние справа можно не писать. Если первая строка — заголовки (Номер, Чип, Забег, ФИО, Год, Команда, Категория), колонки берутся по ним в любом порядке — можно вставить таблицу из Excel как есть. Чип можно не указывать (15;;Забег 1;Иванов Иван) — тогда отметки только от судьи. Категорию можно не писать — возьмётся из забега. ФИО, год и команда нужны только для протокола; храните их с согласия участников.
