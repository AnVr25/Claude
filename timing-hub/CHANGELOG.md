# История версий SakhStart timing-hub (1.3.0 → 7.6.1)

Хронометраж и АРМ секретаря РСОО «ФЛАСО». Сведено из истории коммитов и `docs/`. Даты — 2026 год.
Подробности по релизам — в файлах `docs/`.

## 1.x — основа (8 октября)
- **1.3.0** — исходная версия с сервера reg.fla65.ru без изменений.
- **1.4.0** — обновление сервера кнопкой с GitHub.

## 2.x — новый интерфейс SakhStart (8–12 октября)
- **2.0** — новый интерфейс хронометража в фирменном стиле ФЛАСО.
- **2.1** — вход через браузер, публикация событий на fla65.ru, режим «стадион» (ввод результатов вручную).
- **2.2** — место проведения: адрес и ссылка на карту. **2.3** — адаптация шапки под телефон, ввод спортсменов.
- **2.4–2.6** — создание пользователей без ошибок, понятные сообщения сервера, окно пользователей с примечанием и блокировкой.
- **2.7** — итоги проведённого старта из файла, командный зачёт.
- **2.8** — лимиты мест, диапазоны номеров, эстафеты, выдача пакетов, страница события, копия на год, серии; мастер «Новое соревнование» из трёх шагов.
- **2.8.1** — справочник дисциплин лёгкой атлетики. Автоматическая сборка `timing-hub.zip` через GitHub Actions; обновление сервера — только с ручным подтверждением.
- Отдельно в репозитории: веб-приложение ГТО (`gto/`) со своим обновлением.

## 3.x — Мастер протоколов (13 октября)
- **3.0.0** — новый стартовый экран, мастер подбора соревнования, ручное подтверждение обновлений.
- **3.1.0** — справочник дисциплин для стадиона, типы результата. Разряды, альбомные протоколы, многопопыточный ввод.
- **3.4–3.5** — сетка на 6 попыток для техники, корзина пакетной печати, полный Мастер стартовых и итоговых протоколов бега и техники.
- **3.6** — выполненные разряды по нормам ЕВСК; «Метание мяча/снаряда» (6 попыток).
- **3.7** — автоматическое разделение протоколов по полу и категориям. **3.8** — печать на один лист, ручной ввод разрядов.
- **3.9** — убрано задвоение шагов навигации, чистый Мастер.

## 4.x — судьи, табло, роли (13 октября)
- **4.0** — мобильный АРМ судьи на секторе. **4.1** — настройки системы по вкладкам.
- **4.2** — сквозной аудит, исправлен откат Мастера. **4.3** — маршрут `/sector` для планшетов, трансляция результатов на табло.
- **4.4** — единая навигация и пульт табло. **4.5** — роли Админ / Судья, упорядочены кнопки обновления.
- **4.5.1** — судейская сетка попыток, автоскролл участников на табло. **4.5.2** — «Возобновить соревнование» после «Завершить».

## 5.x — тренеры и персональные данные (13 октября)
- **5.0** — личный кабинет тренера: подтверждение почты, закрытые протоколы. Политика обработки ПДн (152-ФЗ).
- **5.1** — согласие отдельно от Политики, архив редакций согласий, обезличивание заявок, зашифрованные внешние копии.
- **5.2** — нагрудные номера только вручную (шаг 2 Мастера), экспорт стартового протокола в Excel, ручной хронометраж 1–3 секундомера.

## 6.x — реконструкция (14 октября)
- **6.0.0** — интерфейс без «прыжков», единый расчёт результата на сервере, возрасты из справочника, состояние Мастера и корзины в базе.
- **6.1.0** — сквозной номер спортсмена на все его дисциплины; принудительный сброс старта; регистрация без забегов.

## 7.x — стадионно-манежный монолит (14 октября)
- **7.0.0** — удалён чиповый хронометраж (ридеры, IPICO, Wiclax); остался чистый стадион/манеж.
- **7.1.0** — шаг 1 Мастера без обязательных фильтров, кнопка «❌ Очистить все номера дисциплины», безопасный публичный список.
- **7.2.0** — «⚡ Сформировать ВСЕ стартовые протоколы» одним нажатием (сервер сам определяет бег / технику); публичный модуль «Заявленные участники» по образцу MyRace.
- **7.3.0** — на этапе «1. Подготовка» один тумблер «Опубликовать список заявившихся участников»; список в виде плотной таблицы; без плашек у старых согласий.
- **7.3.5** — список участников вынесен в отдельное окно `/r/<slug>/participants` с кнопкой «👥 Участники соревнований» на странице соревнования; колонки: фамилия и имя, год рождения, тренер.
- **7.4.0** — исправлена верстка кнопки участников; колонка «Нагрудный №» с актуальным номером и автообновлением; миграция, подтягивающая год рождения, команду и тренера из заявок; тумблер подтверждения согласий для раскрытия данных.
- **7.4.5** — надёжное сопоставление ФИО при восстановлении года и тренера, «—» вместо пустых ячеек; ссылка на карту манежа с координатами Южно-Сахалинска.
- **7.5.0** — буквенные отметки (днс, днф, дк, нр) на шаге 4 переключают статус сами; «автоточка» в спринте до 400 м; кнопка резервной копии базы (.db); лента аудита в «Система и обновления».
- **7.5.1** — очистка отклонённых заявок, загрузка нагрудных номеров из CSV, сводка-дашборд на шаге 1 Мастера.
- **7.6.0** — глобальный CSV-корректор: выгрузка со всеми рабочими полями и ID заявки, загрузка с проверкой и применением правок ФИО, разрядов, команд, тренеров и номеров по ID.
- **7.6.1** — таблица заявок на всю ширину и длину страницы без полос прокрутки; настройки онлайн-формы убраны в сворачиваемый аккордеон внизу.

## Сквозные принципы
- Официальный результат считается только на сервере. Протоколы закрыты без входа; публично — только список участников (по включённому тумблеру).
- Персональные данные в репозиторий не попадают; открытый список учитывает текст согласия.
- 336 автотестов (`tools/selftest.py`) проходит на каждом релизе.
