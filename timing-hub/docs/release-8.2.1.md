# 8.2.1 — прежний шаблон командной заявки (15.10.2026)
- Возвращён прежний Excel-шаблон «Заявка команды»: колонки «Команда» и «Тренер» на своих местах (H, I), «Разряд / звание*» — K. В 8.0.0 они были убраны, из-за чего позиции колонок сдвинулись, а строка файла без команды при пустом поле «Команда» формы получала ошибку «обязательное поле». Команду и тренера по-прежнему можно не писать в файле, если они указаны в форме.
- `reg.html`: файл проверяется заново, как только «Команда» или «Тренер» в форме поправили после загрузки — не нужно загружать файл повторно.
