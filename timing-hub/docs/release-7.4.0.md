# 7.4.0 — кнопка участников, колонка номеров, восстановление данных (14.10.2026)
- **Кнопка «👥 Участники соревнований»:** причиной «съезжания» был конфликт CSS (кнопка оставалась строчным элементом и не центрировалась). Теперь блочная, по центру, на всю ширину формы; на телефоне текст и иконка по центру без обрывов.
- **Миграция `_migrate_v74`:** при каждом старте у строк участников (`entries`) с пустыми годом рождения, командой или тренером значения подтягиваются из заявок — по связи `reg_id`, затем по ФИО в том же соревновании. Заполненное не перезаписывается.
- **Колонка «Нагрудный №»** в таблице `/r/<slug>/participants`: номер берётся из базы при каждом запросе (то же правило, что на шаге 2 Мастера), ответ без кэша, открытая страница сама обновляется каждые 20 с. Поиск работает и по номеру.
- **Почему у старых заявок не было года и тренера в публичном списке:** это не потеря данных, а скрытие по тексту согласия (заявка подана до появления пункта о публикации). Добавлен тумблер на этапе «Подготовка»: «Показывать год рождения и тренера у всех (согласия на распространение получены)» — с подтверждением, по умолчанию выключен.
