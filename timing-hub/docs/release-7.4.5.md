# 7.4.5 — сопоставление данных, карта манежа (14.10.2026)
- **Миграция `_migrate_v74` усилена:** связь по `reg_id`, иначе по ключу ФИО без регистра, лишних и неразрывных пробелов, «ё» = «е»; добавлено обратное заполнение: если тренер пуст в заявке, но есть в строке сетки — заявка его получает.
- **Список участников:** год рождения и тренер берутся из заявки, а при её пустом поле — из строки сетки. Пустая ячейка выводится как «—».
- **Скрытие по согласию сохранено:** если заявка подана по тексту согласия без пункта о публикации, год и тренер остаются скрытыми (152-ФЗ), пока секретарь не включит на этапе «Подготовка» тумблер «Показывать год рождения и тренера у всех» (подтверждение, что согласия получены).
- **Яндекс.Карты:** ссылка содержит центр карты (манеж — 46.928092, 142.760570, метка и масштаб 17; для остальных мест Южно-Сахалинска — центр города) и текст «Южно-Сахалинск, улица Горького, 39, Легкоатлетический манеж». Раньше поиск шёл по региону посетителя и мог открыть Хабаровск.
- Кнопка «Участники соревнований» — по центру, на всю ширину формы, без изменений поведения.
