# Справочник дисциплин лёгкой атлетики (SakhStart 3.1)

Файл `hub/seed/disciplines.json` собирается скриптом `tools/build_disciplines.py` (правьте скрипт, затем запустите его).
Сервер читает файл при первом обращении, отдаёт его на `GET /api/disciplines` и использует для проверки результатов.

## Что внутри
- **10 групп:** спринт, средние дистанции, длинные дистанции, барьерный бег, стипль-чез, эстафеты, спортивная ходьба, прыжки, метания, многоборья.
- **55 дисциплин.** У каждой: `name` (до 20 символов — как в `reg_distances`), `result` (тип результата), `sex`, `venue` (манеж/стадион), `aliases` (как называют иначе: «Длина», «4x100»), у технических — `attempts` и `max`, у эстафет — `legs`, у барьеров и метаний — `specs` (высоты барьеров, массы снарядов по возрастам), у многоборий — `parts` (состав по дням).
- **Типы результата:** `time` (время, меньше — лучше), `distance` (метры), `height` (метры), `points` (очки многоборья). Для трёх последних больше — лучше.
- **10 пресетов:** манеж, стадион, кубок, дети до 14 лет, многоборье юношей и девушек, прыжки, метания, эстафеты, ходьба.

## Как это работает
- **Выбор при создании события.** Мастер «Новое соревнование» (направление «Стадион») и этап «Регистрация → Настройки формы → Выбрать из справочника»: поиск, фильтр «Манеж / Стадион», готовые программы, чипы по группам. Выбранное записывается в `reg_distances` обычными строками; формат `название | лимит | номера с | эстафета N` не меняется (у эстафет добавляется `| эстафета 4`).
- **Ввод результатов.** Тип результата определяется по дистанции забега. Расстояние и высота вводятся в метрах (`7.85` или `7,85`), очки — целым числом, время — как раньше. Нереальные значения (прыжок на 99 м) отклоняются с подсказкой формата. Места считаются по убыванию для прыжков, метаний и многоборий.
- **В протоколе** у таких результатов есть поля `rtype` и `value`, `seconds` пусто.

## Что пока не делается
- Попытки по отдельности (6 попыток в длину, высоты в прыжках): вводится лучший результат.
- Расчёт очков многоборья по таблице World Athletics: вводятся готовые очки.

## Источники и оговорка
World Athletics Technical Rules (TR 22–23, 24, 32) для барьеров, масс снарядов и составов многоборий; классификация ЕВСК и положения ВФЛА для младших возрастов (до 14 лет, 14–15 лет). Параметры младших возрастов, помеченные «ЕВСК» или «по положению соревнований», сверяйте с положением конкретного старта.
