# 8.3.1 — меньше лишнего: список соревнований, без загрузки из Excel и без корзины печати (15.10.2026)
- **Выпадающий список соревнований** больше не вылезает за экран: длинные названия переносятся по словам, при большом числе соревнований список прокручивается (высота не больше экрана).
- **Регистрация:** кнопка «Загрузить из Excel» убрана — заявки и новые участники грузятся одним способом, CSV («Выгрузить CSV» → правка → «📥 Загрузить CSV»; строки без ID — новые участники). Серверный разбор файлов тренеров на публичной странице не менялся.
- **Корзина печати убрана:** нет блока «Корзина печати» внизу Мастера, нет кнопки «🛒 Добавить текущую вкладку в корзину печати» над протоколом. Печать — кнопка «🖨 Печать» шага 3 и «Протокол для печати» итогов; Excel и CSV — выгрузкой.
- Внутри остались серверные методы корзины (совместимость), в интерфейсе их нет.
