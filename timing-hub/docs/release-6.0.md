# 6.0.0 — генеральная реконструкция (14.10.2026)

Основа — `global_system_snapshot.md` (аудит 5.2.0). Новых функций нет: убраны дубли, прыжки экрана и расхождения между секретарями.

## 1. Экран не прыгает
- Нет принудительной прокрутки при переходах между шагами Мастера и после сохранения результатов. Остался один `window.scrollTo(0,0)` —
  только при переходе между разделами админки (другой адрес `#…`), чтобы новый раздел открывался сверху. `scrollIntoView` удалены полностью.
- Перерисовка Мастера держит высоту, не двигает прокрутку и возвращает фокус в ту же ячейку; ручное «Сохранить результаты»
  обновляет только расчётные клетки (без полной перерисовки). Чужое изменение не применяется, пока вы вводите данные.
- Панель этапов — всегда на месте и фиксированной высоты 68 px (раньше пряталась на «Главной» и в «Системе», высота плавала
  от подписей). Этапы пронумерованы 1–7 в разметке (двойник «3» убран); без выбранного соревнования панель серая и неактивная.
- «5. Ввод результатов» (стадион, ручной ввод) открывает шаг 4 Мастера и подсвечивает этап 5; клик по «3. Протоколы» с шага 4 возвращает на шаг 3.

## 2. Одно правило — одно место
- Официальный результат (3 секундомера → средний, 2 → худший, 1 → сам, вверх до 0,1 с; попытки → лучшая) считает только сервер:
  `Hub.official_from_raw`, его же использует приём результатов. Браузеры (админка, планшет сектора) шлют сырые цифры в
  `POST /api/calc {distance, rows:[{key, t|a}]}` и показывают ответ. Из `ui.html` и `sector.html` удалены `parseT/fmtT/swMain/attBest`.
  Без связи итог в ячейке не обновляется — сервер посчитает его при сохранении строки.
- Границы возрастных групп — только в `hub/seed/disciplines.json` (`ages[].min/max`, версия справочника 3). Сервер: `Hub.age_limits()` и `Hub.age_ok()`
  (три копии проверки заменены одной); Мастер берёт границы из `/api/disciplines`.
- Удалён старый экран «Ввод результатов» (разметка, ~130 строк JS, стили, опрос раз в 3 с).

## 3. Общее состояние секретарей
Таблица `ui_state(event_id, key, value, rev, who, cid, updated_at)`; `GET/POST /api/events/{id}/ui`.
- `wizard` — дисциплина, шаг, пол, возрастные группы Мастера. Последний записавший выигрывает; экран опрашивает сервер раз в 3 с.
- `cart` — корзина печати. Операции `add / remove / toggle / clear` складываются на сервере, поэтому два секретаря не затирают друг друга;
  протокол в предпросмотре добавляет листы сразу на сервер и сообщает об этом админке.
- В `localStorage` остались только личные настройки вида (последний этап, фильтры страницы протокола).

## Сохранено без изменений

табло (сквозной автоскролл, цветные ячейки попыток), экспорт в Excel.
