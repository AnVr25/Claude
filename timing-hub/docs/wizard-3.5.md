# 3.5.0 — мастер протоколов (бег и техника)

Вкладка **«Протоколы»** (для соревнований «Стадион») ведёт секретаря по пяти шагам. Тип дисциплины определяется сам по справочнику: попытки или результат «расстояние/высота» — **техника**, время — **бег**.

| Шаг | Бег | Техника |
|---|---|---|
| 1. Фильтр | возрастные группы и пол | то же; участники другого пола не пропадают |
| 2. Сетка | забеги и дорожки; «❌ Удалить все забеги» | только «Общий список», дорожки заблокированы и на сервере; «❌ Сбросить список» |
| 3. Стартовый протокол | вертикальный, «Сек. 1 / Сек. 2 / Сек. 3» | горизонтальный, «Попытка 1…6» и «Лучший результат» |
| 4. Ввод | три времени; официальный результат считает сервер | шесть попыток (X, «-»); лучшую находит и проверяет сервер |
| 5. Итоговый | вертикальный: места, результаты, выполненные разряды | горизонтальный: все шесть попыток у каждого места |

## Что важно знать
- **Выборочная сетка.** `POST /api/events/<id>/heats` с `distance` (+ `ages`, `sex`, `lanes`) пересобирает только одну дисциплину; остальные дисциплины, номера и введённые результаты не трогаются. Без `distance` работает прежняя полная сборка.
- **Смешанный «общий список».** Раньше у такого забега не было дистанции, и прыжок читался как время. Теперь дисциплина берётся у каждого участника из заявки (`entry_dists`).
- **Выполненный разряд** вносит секретарь на шаге 4 (поле `done_rank`). Автоматического расчёта по нормативам ЕВСК нет: таблицы нормативов нужно сверять отдельно.
- **Корзина печати** общая для мастера и «Регистрации»: листы с галочками, «🖨️ Печать пакета» (один документ, каждый лист с новой страницы, бег книжный, техника альбомный), «🌐 Выгрузить в общую сеть» (`POST /api/events/<id>/publish`, `start`/`results`). На публичной странице открывается протокол соревнования целиком, не отдельные листы.
- **Разряд / звание** обязателен при регистрации, в карточке участника и при добавлении вручную (проверяется и на сервере).
