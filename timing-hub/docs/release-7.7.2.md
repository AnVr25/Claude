# 7.7.2 — печатные бланки строго по А4, разворот бега в альбомный лист (14.10.2026)
- **Жёсткий А4.** Лист на экране — `.sheet.port` 210×297 мм или `.sheet.land` 297×210 мм (`box-sizing:border-box`, по центру); внутри листа секции `.cp` занимают 100% ширины. Таблицы, шапка (`.phead`), примечания (`.tail`) и подписи (`.sign`) растянуты на всю ширину без `max-width`.
- **Печать.** `html, body { margin: 0; padding: 0 }`; поля листа задаёт только `@page` (12/14 мм, у альбомного 10/12 мм), контейнер в печати — 100% печатной области, поэтому бланк не сжимается, не съезжает в угол и поля принтера не дублируются. Если бы контейнер печатался шириной 210 мм **плюс** поля `@page`, он вылезал бы за лист — поэтому в печати мм-размеры заменены на 100% области. Таблицы — `table-layout: fixed`; таблицы попыток и секундомеров (`.att`, `.swt`) считают колонки по содержимому и растягиваются на всю ширину.
- **Ориентация.** Беговые бланки по умолчанию вертикальные (3 секундомера), техника всегда горизонтальная (6 попыток). Селектор «Ориентация листа» в меню протокола теперь доступен для стартовых (по забегам и общим списком) и итоговых бланков бега; `setPage(true)` сразу перестраивает лист на 297 мм, таблицы секундомеров растягиваются. Выбор сохраняется и попадает в корзину печати. У командного зачёта селектор скрыт.
- Все модули 7.7.1 сохранены (кнопки CSV/Excel над таблицей, правка шапок бланков без пунктира в печати, дашборд шага 1, очистка отклонённых, сквозной номер по `registrations.id`, кабинеты тренеров). Внешней сети страницы не требуют.
- Версия 7.7.2, потому что 7.7.1 уже выпущена, а встроенный апдейтер сравнивает номера версий.
