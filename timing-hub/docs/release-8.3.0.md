# 8.3.0 — компактный Мастер протоколов (15.10.2026)
- **Шаг 3.** Один ряд действий вместо трёх: `⚡ Сформировать забеги / общий список` · `⚡ Все дисциплины` · `❌ Сбросить сетку` · «Дорожек» · число участников, а справа — `📊 Excel` и `🖨 Печать`. Верхняя большая кнопка «Сформировать ВСЕ стартовые протоколы» убрана (теперь это «Все дисциплины» в том же ряду, итог её работы показывается тут же). Четыре строки подсказок свёрнуты в «Как это работает».
- **Шаг 2.** Две строки пояснений — в одну; кнопки обычного размера: `💾 Сохранить номера`, тихая `❌ Очистить номера`.
- **Шаг 4.** Подсказка про секундомеры и разряд свёрнута («Как вводить»); поля ввода невысокие (30 px, 70 px по ширине), селекторы разряда и отметок уже; строки плотнее; «Очистить протокол» — тихая кнопка. Живой поиск — тоньше.
- Общие правила: действие «главное» — красная кнопка, второстепенные — обычные, разрушающие («Сбросить», «Очистить») — тихие красные; ни одна кнопка не повторяется на экране. Нижняя навигация «← Назад / далее →» осталась единственным способом идти по шагам вперёд.
