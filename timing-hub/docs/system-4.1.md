# 4.1.0 — «Система» по вкладкам

Шестерёнка → «Система». Одна строка вкладок на всех экранах раздела, всегда на одном месте (под полосу прокрутки место зарезервировано, поэтому страница не прыгает):

| Вкладка | Адрес | Что внутри |
|---|---|---|
| ⚙️ Общие настройки и обновления | `#hw` | Сервер (версия, время работы, часы, сайт, сертификат), ресурсы (память, диск, база, резервные копии), службы, обновление сервера с проверкой на GitHub и журналом |
| 📟 Хронометраж и оборудование (IPICO, Wiclax) | `#hw-timing` | Ридеры (поиск, добавление, загрузка списка, симулятор, связь, часы ридера), Wiclax (подключения, порты, порты по точкам), последние отметки и выгрузки |
| 🔒 Сетевые доступы и VPN | `#hw-net` | VPN-доступы (OpenVPN), WireGuard, кто открывал сервер за последний час |
| 👥 Пользователи | `#users` | учётные записи: администраторы, секретари, судьи на финише, судьи на секторе |
| Журнал действий | `#log` | кто и что менял |

- **Права.** Первые четыре вкладки видит только администратор, секретарю доступен журнал.
- **Ссылки из шапки.** «Ридеры», «Wiclax» и «Оборудование IPICO» ведут сразу во вкладку хронометража, «VPN» — во вкладку сетей.
