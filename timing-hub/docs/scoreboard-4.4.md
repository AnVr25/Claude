# 4.4.0 — единая навигация и пульт управления табло

## Навигация
Верхняя строка этапов «1. Подготовка … 7. Документы» больше не скрывается в Мастере протоколов.
Шаги Мастера (1 Фильтр … 5 Итоговый) показываются под ней как вложенное меню, этап «3. Протоколы» подсвечен.
Кнопка «← К этапам соревнования» убрана: строка этапов всегда на месте.

## Пульт управления табло
Страница `/scoreboard?event=ID`. Её же открывают меню «Экраны» → «🎛️ Пульт управления стадионным табло»
и адрес `/api/system/scoreboard/control` (переадресация на пульт).

Режимы:
- **Авто-трансляция** — последние введённые результаты, новые сверху (как раньше).
- **Фиксация дисциплины** — таблица лидеров одной группы «дисциплина · категория», с 1 места до последнего,
  по 10 строк, страницы листаются каждые 8 с.
- **Ротация / слайд-шоу** — по кругу группы с галочкой «в ротации» (без галочек — технические виды с результатами),
  смена каждые 5–120 с (по умолчанию 15). Все телевизоры показывают один и тот же слайд — отсчёт по часам сервера.

Справа на пульте — живое превью табло.

## API
- `GET /api/scoreboard/state?event=ID` — режим, выбранная группа, ротация и список групп с числом результатов.
- `POST /api/scoreboard/state` — `{event_id, mode: "auto"|"fixed"|"rotate", group|wave_id: "дисциплина|категория",
  rotate: {interval, groups}}`. Сохраняется в таблице `scoreboard`, ответ — новое состояние. Запись в журнал действий.

Табло опрашивает состояние каждые 1,5 с и перестраивается без перезагрузки страницы.

## Права
Переключать табло могут админ, секретарь и судья на финише. Судья на секторе видит состояние, но не переключает.
`/board` теперь разрешено встраивать в страницы самого хаба (X-Frame-Options: SAMEORIGIN) — для превью на пульте.
