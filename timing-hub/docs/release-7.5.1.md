# 7.5.1 — номера из CSV, очистка отклонённых, сводка на шаге 1 (14.10.2026)
- **«❌ Очистить отклонённые заявки»** — вкладка «Отклонены» этапа «Регистрация», с подтверждением. `POST /api/events/<id>/clear-rejected` (`Hub.clear_rejected`): в одной транзакции удаляет из `registrations` все заявки со статусом `rejected` этого соревнования (и остатки их строк в `entries`), пишет в аудит. Другие статусы и соревнования не затрагиваются.
- **CSV с номерами в обе стороны.** Выгрузка «Заявки …csv» теперь содержит колонку «Нагрудный номер» (актуальный номер из заявки или сетки; пусто — впишите). Кнопка «📥 Загрузить номера из CSV» → `POST /api/events/<id>/bibs-csv` (`Hub.bibs_from_csv`): строки сопоставляются по «№ заявки», пустые ячейки пропускаются, запись идёт методом `save_bibs` (все или ничего, один человек — один номер на все дисциплины, повтор у разных людей отклоняется). Шаг 2 читает номера из базы, поэтому показывает их сразу; список участников на сайте тоже.
- **Шаг 1 Мастера — сводка:** «Всего подтверждено: X участн. (Мальчиков: A, Девочек: Б) · до 12 лет: В · до 14 лет: Г…», информационные счётчики вместо кнопок-фильтров, строка про вписанные номера и ждущие заявки. Возрастная группа — самая узкая из подходящих (каждый учтён один раз).
