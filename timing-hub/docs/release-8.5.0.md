# 8.5.0 — быстрая навигация по Мастеру: фильтр наверху, дисциплина не перекидывает на номера (17.10.2026)
- **Ошибка исправлена.** Выбор дисциплины в списке «Дисциплина» принудительно переводил Мастер на шаг 2 («Нагрудные номера»). Теперь секретарь остаётся на том же шаге — ввод результатов, стартовый или итоговый протокол — и видит выбранную дисциплину.
- **Липкая полоса наверху** (остаётся на экране при прокрутке): дисциплина · пол (Все / Мальчики / Девочки) · возрастные группы · шаги 1–5. На шагах 2–5 фильтр один и тот же; убран дубль фильтра внутри шага 2.
- **Фильтр действует везде:** на списке номеров (шаг 2), стартовом протоколе (шаг 3: бланк, печать, Excel), вводе результатов (шаг 4: в таблице остаются только выбранные), итоговом протоколе (шаг 5: бланк и Excel). В бланк возрастные группы передаются диапазонами годов рождения (`yr`).
- При смене дисциплины фильтры сбрасываются.
