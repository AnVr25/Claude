# 8.5.2 — адаптивная вёрстка форм на планшете и телефоне (17.10.2026)
- **Подготовка → «Параметры соревнования».** На iPad поля «Дата начала» и «Дата окончания» налезали друг на друга, длинные подписи сдвигали ряды. Теперь ячейки сетки не распирают колонки (`min-width:0`), колонки подбираются по ширине экрана (`minmax(min(100%, 210px), 1fr)`), поля даты и времени не держат собственную ширину iOS/Safari (`appearance:none`), подписи укорочены («Дата окончания», «Начало (для протокола)», «Организатор (в шапку)»).
- То же правило — для блока «На сайте fla65.ru» и общей сетки `.grid`.
- Проверено в Chromium при 375, 768, 834, 1000 и 1180 px (тёмная тема): горизонтальной прокрутки страницы нет; широкие таблицы («Регистрация») прокручиваются внутри своей рамки.
