# 8.0.0 — олимпийский монолит: Excel по образцу ВФЛА, живой поиск на финише, форма без дублей (15.10.2026)
Образец — файл «Муниципальные соревнования по кроссу» (стартовые протоколы по группам и итоговый с командным зачётом).

**1. Excel-протоколы по образцу ВФЛА (`hub.py`)**
- Новый генератор `xlsx_doc` (шрифты, границы, заливки, объединённые ячейки, формулы, разрывы страниц, печать на А4). Старый `xlsx_build` остался для шаблона заявки.
- `GET /api/events/<id>/startlist.xlsx` — стартовый и **новый** `GET /api/events/<id>/results.xlsx` — итоговый протокол. Фильтры: `distance`, `sex`, `ages`; `orient=landscape` разворачивает беговой лист.
- Шапка в каждом протоколе: «МИНИСТЕРСТВО СПОРТА САХАЛИНСКОЙ ОБЛАСТИ», ФЛАСО, СШОР им. Комнацкого, название, место и дата, заголовок, группа («ДЕВОЧКИ 2017-2018 г.р.»), дисциплина с массой снаряда, время начала; внизу — главный судья и секретарь, дата формирования, количество участников. Каждая группа/забег — с новой страницы.
- Бег — книжный лист, 3 секундомера; техника — альбомный, 6 попыток. **Место** — формула `RANK`, **лучший результат** — `MAX` по попыткам, **очки** — по шкале 20-17-15-14…1 (если очки введены вручную — они), **командный зачёт** — `SUM` и `RANK` на отдельном листе.
- Масса снаряда (`implement_weight`): ядро М 20+ — 7,26 кг, 18–19 — 6, 14–17 — 5, до 13 — 4; Ж 18+ — 4 кг, младше — 3; мяч — 150 г; вес в названии дисциплины главнее. Участники с разной массой — отдельные протоколы. Таблицу масс нужно сверить с положением соревнований.
- **Без «NaN».** `entries_rows` берёт пустые ФИО, год, команду, тренера, пол, разряд и категорию из `registrations` по `reg_id` (LEFT JOIN); `xl_clean` не пропускает `nan/None/null`, а NaN-числа не записываются в файл.

**2. Живой поиск на шаге 4 Мастера** — `<input id="judge-finder">` над таблицей: цифры — по началу нагрудного номера, буквы — по началу фамилии; лишние строки скрываются на лету, Enter переводит в поле первой найденной строки, Esc очищает. Сохранение результатов скрытых строк не затрагивается.

**3. Онлайн-форма (`reg.html`)** — вверху инструкция «Просим вас заполнять поля онлайн-формы строго в соответствии со знаками звёздочек (*)»; «Тренер» обязателен; в шаблоне Excel команды больше нет колонок «Команда» и «Тренер» (вводятся один раз в форме; старые файлы с этими колонками читаются). Плашка успеха: «Спасибо за регистрацию!» и предупреждение о появлении в открытых списках только после модерации и утверждения Главным секретарём.

**4. Печать А4 и автономность** — без изменений с 7.7.2: лист 210×297 / 297×210 мм на экране, в печати 100% области между полями `@page`, ручной разворот бега; шрифты Oswald и PT Sans, иконки и QR — локально (Roboto в проекте не используется). `Запустить_СахСтарт.bat` и автосоздание `config.json` сохранены.
