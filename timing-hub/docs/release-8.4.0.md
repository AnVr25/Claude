# 8.4.0 — время начала строго по программе; поиск заявок по нагрудному номеру (16.10.2026)
**Время начала из «Подготовки».** Секретарь пишет программу в карточке «Подготовка» (поле «Программа», по строке: `10:00 | 60 м девочки до 14 лет`). Сервер (`Hub.program_time`) сопоставляет строки с дисциплиной и категорией каждого блока и отдаёт время (`ptimes` в стартовом списке и результатах, в том числе на публичных страницах):
- шапка стартового и итогового протокола — «Начало: ЧЧ:ММ» из программы; у каждого блока — «· начало ЧЧ:ММ»;
- Excel-книга: «Время начала» в каждом блоке стартового листа и «ИТОГ» — из программы.
- Правила сопоставления: дисциплина названа в строке (`60 м` не путается с `60 м с/б` и `160 м`); если строк несколько — выбирается та, где совпали пол (девочки / мальчики…) и возраст («до 14 лет»); для диапазона «10:20 – 11:00» берётся начало. Нет строки в программе — подставляется прежнее значение (фактическое время старта забега, затем «начало» события), поле «Начало» в бланке по-прежнему можно поправить кликом.
- Изменилась программа — поправьте её в «Подготовке», протоколы подхватят сами.

**Поиск в «Регистрации».** В поле поиска заявок цифры ищут по нагрудному номеру (номер в заявке или в сетке, по началу), буквы — по фамилии, имени, команде, тренеру. Подсказка: «Фамилия, команда, тренер или № участника».
