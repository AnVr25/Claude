# 7.7.5 — финальный стадионный монолит, запуск судьями двойным кликом (14.10.2026)
- **Запускчик для Windows:** `Запустить_СахСтарт.bat` в корне проекта. Двойной клик: переходит в папку проекта, запускает `python hub\hub.py` (если `python` нет в PATH — `py`), через 3 секунды открывает `http://localhost:8080/`. Окно с сообщением «НЕ ЗАКРЫВАЙТЕ» должно оставаться открытым — это и есть сервер; закрытие окна останавливает сервер. Если Python не найден — понятное сообщение.
- **Первый запуск:** `config.json` и `reads.db` создаются сами рядом с проектом (7.7.3). Запускчик нарочно не передаёт `--config`: явно заданный, но отсутствующий файл — ошибка, а запуск без него создаёт локальный.
- **В сборке (всё в одной ветке, одна версия):** пакетная генерация всех протоколов («Сформировать всё»), публичный список участников с тренерами и годами рождения (скрытие по согласию), печатные бланки строго А4 с ручным разворотом бега в альбомный лист, правка шапок бланков (`contenteditable`), CSV/Excel-кнопки над таблицей заявок, CSV-корректор, очистка отклонённых, сквозные номера по `registrations.id`, кабинеты тренеров; страницы без внешних загрузок (шрифты и QR локальные).
