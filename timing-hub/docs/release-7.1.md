# 7.1.0 — короче шаг 1, очистка номеров, безопасные публичные списки (14.10.2026)

## 1. Шаг 1 Мастера
Выбор дисциплины в выпадающем списке сразу переводит на шаг 2 «Нагрудные номера»: все подтверждённые участники дисциплины подгружаются автоматически, ничего нажимать не нужно. Шаг 1 остался короткой справкой (сколько участников, сколько ждут проверки). Пол и возраст — необязательные вкладки-пилюли «Все / Мальчики / Девочки» и возрастные группы из справочника `AGES` (`seed/disciplines.json`); они дублируются над таблицей номеров. Без выбора вкладок в сетку идут все участники дисциплины.

## 2. «❌ Очистить все номера дисциплины» (шаг 2)
Красная кнопка рядом с «💾 Сохранить нагрудные номера». Запрос `POST /api/events/<id>/clear-bibs {distance}` после подтверждения («Вы уверены, что хотите ПОЛНОСТЬЮ стереть и очистить все нагрудные номера в этой дисциплине?») выставляет `bib = NULL` у всех заявок дисциплины; поля на экране пустеют.
- Номер принадлежит человеку, поэтому он стирается и в других его дисциплинах (иначе вернулся бы как «подставленный»); в окне подтверждения об этом сказано.
- Строки сетки этих людей удаляются, опустевшие забеги — тоже, время старта сбрасывается. Формировать список нужно заново.
- Если у кого-то уже введён результат, очистка отклоняется целиком: сначала «Очистить протокол» на шаге 4.

## 3. Публичные списки для тренеров
- Открытый «Список прохождения регистрации» на странице формы (`reg.html`, блок «Списки прохождения регистрации», поиск по фамилии): **только** «Фамилия И.», возрастная группа из `AGES` и дисциплины одобренных заявок; для эстафет — только название команды. Ни номеров, ни дорожек, ни дат рождения, ни команд, ни контактов.
- Включается секретарём: переключатель «Открытый список „прошли регистрацию“» на этапе «2. Регистрация» или галочка на шаге 5 (поле `pub_regs`, по умолчанию выключено). Данные отдаёт `GET /r/<код>/registered.json` (с ограничением частоты запросов).
- Стартовые и итоговые протоколы по-прежнему закрыты: их видят только вошедшие тренеры, судьи и организаторы (личный кабинет). Кнопки «Выгрузить в общую сеть» заменены на «Открыть тренерам в кабинете» — в открытый доступ протоколы не попадают.
