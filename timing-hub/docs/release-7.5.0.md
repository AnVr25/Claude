# 7.5.0 — быстрый ввод судьи, резервная копия и лента аудита (14.10.2026)
- **Буквенные отметки на шаге 4:** «днс, dns, нс, н/с» → DNS; «днф, dnf» → DNF; «dq, дк» → DQ; «нр, nm» → NM. Ячейка очищается, список «Отметка» (`select.stsel`) переключается, строка сохраняется сразу.
- **«Автоточка» в спринте** (`Hub.parse_result(text, sprint)`, `Hub.sprint_meters`): для бега до 400 м включительно набранное целое из 2–3 цифр читается как десятые (95 → 9.5, 123 → 12.3). Действует только на набранное (секундомеры, ручной ввод), а не на сохранённый текст — иначе сохранённые «13 с» превратились бы в 1.3. Если десятые дали бы нереальное время (быстрее дистанция/12 с), остаётся прежнее чтение: «25» на 200 м — 25 с.
- **Резервная копия:** кнопка «📥 Создать и скачать резервную копию базы данных (.db)» на вкладке «Система и обновления»; `GET /api/system/backup/db` (только администратор) делает слепок через SQLite backup API, пишет событие в аудит. Файл содержит ПДн.
- **Лента аудита:** блок «Журнал действий пользователей (Аудит)» на вкладке «Система и обновления»; `GET /api/system/audit?limit=50` (только администратор): время · исполнитель · действие · детали.
