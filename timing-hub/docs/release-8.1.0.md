# 8.1.0 — интеллектуальный CSV-валидатор: новые участники из Excel (15.10.2026)
Остальное из запроса (Excel-протоколы ВФЛА без NaN, живой поиск `judge-finder`, инструкция и плашка модерации в `reg.html`, печать А4 с разворотом бега, офлайн и `Запустить_СахСтарт.bat`) выпущено в 8.0.0 и сохранено; автотесты покрывают всё.

**«Регистрация» → «📥 Загрузить и применить изменения из CSV» (`POST /api/events/<id>/regs-csv`, `?check=1` — только проверка)**
- Строка с **пустым или отсутствующим ID заявки** больше не ошибка, а **новый участник**. Колонки: Фамилия, Имя, Год рождения, Дисциплина (или «Дистанция»), необязательные Пол, Отчество, Разряд, Команда / Клуб, Тренер, Нагрудный номер, Категория. Файл вообще без колонки ID читается как список новых участников.
- Обязательны **Фамилия, Имя, Год рождения, Дисциплина**. Нет поля — импорт останавливается целиком, ничего не пишется, окно-ошибка показывает: «Строка N: Ошибка импорта! Не заполнено обязательное поле «…». Пожалуйста, скорректируйте данные в Excel и повторите загрузку.» (по строке на каждое поле, номер строки — как в Excel).
- Дальше проверка как у обычной заявки: дисциплина должна быть в программе соревнований, год — 4 цифры или дата, пол — «М/Ж» (если колонки «Пол» нет — по слову в «Категория»: мальчики/юноши…, иначе ошибка по полю «Пол»), формат номера. Разряд по умолчанию «Б/р», команда «—».
- Успех: новая запись `registrations` (новый `id`) со `status='approved'`, согласие/политика записываются как у импорта секретаря, **нагрудный номер**: из файла, иначе уже стоящий у этого человека, иначе следующий свободный; номер один на все виды человека. Человек сразу виден на шаге 2 Мастера и в списках. Всё записывается одной транзакцией вместе с правками существующих строк.
- Повторная загрузка того же файла заявки не дублирует. Строка с ID, которого нет в соревновании, остаётся ошибкой — опечатка в ID не должна молча создать нового человека.
- Год рождения хранится датой `ГГГГ-01-01`, если в файле только год (категория считается по году).
- `ui.html`: вместо системного `alert` — окно «Импорт остановлен — ничего не загружено» со списком строк; в подтверждении перед загрузкой — число новых участников и примеры.
