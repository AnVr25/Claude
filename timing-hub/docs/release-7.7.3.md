# 7.7.3 — запуск на Windows без /etc/timing-hub (14.10.2026)
- Без `--config` сервер берёт `./config.json` из текущей папки (раньше — `/etc/timing-hub/config.json`, которого на Windows нет).
- Нет файла — сервер создаёт его сам и продолжает запуск: база `reads.db` рядом, страница `http://127.0.0.1:8080/`, форма регистрации выключена, пароль пустой (доступ только с этого компьютера; задайте `web.password`, если нужен вход по паролю).
- Явно заданный `--config` ведёт себя как раньше: если файла нет — ошибка, ничего не создаётся (опечатка в пути на рабочем сервере не должна молча подменить настройки). Служба на сервере запускается с явным `--config`, поэтому не затронута.
- Запуск на Windows: `python hub\hub.py` из любой папки — файлы `config.json` и `reads.db` появятся в ней.
- Версия 7.7.3: 7.7.2 уже выпущена (печатные бланки), а апдейтер сравнивает номера версий.
