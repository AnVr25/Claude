# 5.2.0 — АРМ секретаря: ручные нагрудные номера, единая цепочка Мастера, Excel

## 1. Нагрудные номера — только вручную
- Автоматическое присвоение и инкремент номеров удалены с сервера (`get_next_bib`, `next_bib`).
  Сервер не создаёт участника сетки без номера: генерация забегов/общего списка и поздняя заявка
  отвечают 400 «впишите номер на шаге 2».
- **Шаг 2 Мастера «Нагрудные номера»** — таблица подтверждённых участников по фильтру шага 1
  (дисциплина, пол, возраст), поле номера у каждого. Enter — к следующему полю, на последнем — сохранение.
- Живая проверка: пустые, повторы (подсвечиваются), несохранённые. Кнопка «💾 Сохранить нагрудные номера»
  выключена, пока есть повторы. **Без нажатия в базу ничего не пишется**; при уходе с шага, смене дисциплины
  или закрытии вкладки с несохранёнными правками — предупреждение.
- Сохранение атомарно (`POST /api/events/{id}/bibs {rows:[{ids,bib}]}`): при любой ошибке не сохраняется ничего.
  Номер уникален в пределах соревнования; эстафетная команда — один номер.
- Номера можно править в любой момент, в том числе после формирования сетки и ввода результатов:
  номер переезжает в сетку и результаты вместе со спортсменом (обмен номерами двух участников тоже работает).
  Стереть номер у участника, стоящего в сетке, нельзя. Каждое сохранение — запись в журнале.
- Ограничение: номер уникален в соревновании, поэтому спортсмен в двух дисциплинах получает два номера.

## 2. Единая цепочка
Верхняя панель 1–7 — этапы соревнования. Внутри этапа «Протоколы» — Мастер:
1. Фильтр участников (пол, возраст) → 2. Нагрудные номера → 3. Забеги / общий список, сброс сетки
(с подтверждением), Excel → 4. Ввод на финише / с сектора, разряды ЕВСК, «🛑 Отменить старт / Сбросить время» →
5. Итоговый протокол, корзина печати, публикация, «Завершить / Возобновить».
- Шаг 3 без номеров заблокирован и ведёт на шаг 2.
- Для стадиона с ручным вводом этап «5. Ввод результатов» открывает шаг 4 Мастера (без второго экрана ввода).
- Этап «4. Выдача номеров» — отметки физической выдачи, номера там не присваиваются.

## 3. Стартовый протокол в Excel
Шаг 3 → «📊 Выгрузить стартовый протокол в Excel (.xlsx)» (`GET /api/events/{id}/startlist.xlsx?distance=&sex=&ages=`).
- Общие колонки: № п/п, Нагрудный номер, Фамилия, Имя, Год рождения, Разряд, Команда / Город.
- Бег: Забег №, Дорожка, Секундомер 1–3 (пустые); книжный лист, по забегам, по дорожкам.
- Техника: Порядок выполнения, Попытка 1–6, Лучший результат (пустые); альбомный лист.
- Строка заголовков повторяется на каждой печатной странице. Файл собирается без внешних библиотек.

## 4. Ручной хронометраж
- На шаге 4 можно ввести 1, 2 или 3 секундомера. Официальный результат: 3 — средний (медиана), 2 — худший,
  1 — само значение; округление вверх до 0,1 с.
- На табло и в итоговом протоколе — только официальный результат, без столбцов секундомеров.
