# 8.6.0 — диктор с выбором дисциплины; очередь участников на табло и у диктора (17.10.2026)
- **Экран диктора (`/announcer?event=…`).** Сверху — крупный список «Все дисциплины / дисциплина · категория — сколько есть результатов из скольких заявлено». Выбор запоминается на устройстве (и задаётся ссылкой `&group=Дисциплина|Категория`), экран фильтруется: «Только что финишировал», «Перед ним» и счётчики — только по выбранной группе. Подходит для нескольких параллельных дисциплин, удобно с телефона.
- **«Готовятся дальше».** Между «только что» и «перед ним» — следующие 6 участников выбранной дисциплины без результата: номер, фамилия, команда, пометка «ждёт». Участники с отметкой DNS/DNF/DQ в очередь не попадают.
- **Табло (`/board`), таблица группы.** После участников с результатами идут приглушённые строки очереди — место пустое, пустые ячейки попыток (для техники) и надпись «далее». Видно, кто будет выступать следующим. Длинные таблицы по-прежнему плавно прокручиваются.
- Для техники и бега на экране диктора вместо «время» теперь показывается итоговый результат (метры/секунды), сортировка — по времени финиша или ввода результата.
- Режим «последние результаты» на табло не менялся: очередь показывается в режимах «таблица группы» и «по кругу».
