# 7.2.0 — публичный список участников и пакетная генерация протоколов (сборка 14.10.2026)

## 1. Публичный модуль «👥 Заявленные участники» (`/r/<slug>`, `hub/reg.html`)
- Раздел расположен выше блока документов, открыт без входа; по образцу MyRace.
- Выпадающий список дисциплины (со счётчиком), переключатели пола (Все / М / Ж) и возрастных групп
  (из справочника AGES; показываются только встречающиеся), поиск по фамилии.
- Сквозной список: № п/п, Фамилия Имя, год рождения и разряд, команда / школа / город, тренер.
  «Показать ещё» — порциями по 50; эстафеты — названия команд.
- Данные: `GET /r/<slug>/participants.json` (404, пока публикация выключена; ограничение частоты запросов).
  Номера, даты рождения, контакты и представители не отдаются.
- Судейские бланки, стартовые и итоговые протоколы остаются закрытыми (кабинет тренера / вход).
- Включается переключателем «Открытый список» на этапе «Регистрация» (по умолчанию выключено).

### Персональные данные
Публикация ФИО, года рождения, разряда, команды и тренера — распространение ПДн. Текст согласия теперь содержит
соответствующую фразу. Для заявок, поданных по старому тексту согласия (без этой фразы), в открытом списке
показывается только «Фамилия И.» и пометка «данные скрыты». Рекомендация (ст. 10.1 152-ФЗ): ввести отдельную
отметку согласия на распространение.

## 2. Пакетная генерация протоколов
- Шаг 3 Мастера: «⚡ Сформировать ВСЕ стартовые протоколы соревнований».
- `POST /api/events/<id>/heats-all`: по каждой дисциплине с одобренными заявками сервер сам выбирает вид
  (бег — забеги и дорожки; техника — общий список на 6 попыток) и формирует протокол одним проходом.
- Дисциплины без нагрудных номеров, со стартовавшим стартом и т. п. пропускаются с причиной — итог выводится на экране.
  Номера автоматически не присваиваются.
- Красная кнопка «❌ Очистить все номера дисциплины» (шаг 2) сохранена.
