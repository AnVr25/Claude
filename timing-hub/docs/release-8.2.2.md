# 8.2.2 — командная заявка: данные команды только из Excel (15.10.2026)
- На сайте в режиме «Заявка командой» **убрана карточка «Команда»**: поля «Команда / школа / город», «Тренер / представитель команды» и «Телефон или e-mail» больше не вводятся второй раз. Остаётся: инструкция про звёздочки, шаблон, загрузка файла, согласия.
- Команда и тренер берутся из колонок файла **«Команда*» и «Тренер*»** (обязательные, на прежних местах H и I шаблона). Нет команды или тренера в строке — ошибка именно этой строки («укажите команду / тренера в файле»), как и раньше при другой ошибке в строке; файл не принимается, пока строки не исправлены.
- Сервер больше не требует телефон/e-mail команды. Старые клиенты, присылающие `team`/`coach` в запросе, по-прежнему принимаются: они подставляются, если в строке файла пусто.
- Шаблон Excel: заголовки «Команда*», «Тренер*», подсказка «на сайте их отдельно вводить не нужно».
- Заявка одного участника и эстафеты не менялись (там поля остаются).
