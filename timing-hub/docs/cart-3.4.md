# 3.4.0 — сетка техники и корзина печати

**Где живут бланки.** Печатные формы стартовых протоколов собираются в `hub/protocol.html` (функции `startSheet()` и `table()`), а не в `ui.html`. В админке (`ui.html`) только выбор вида и корзина.

## Бег и техника
- Если у дисциплины тип результата `distance` или `height` (или есть попытки), бланк всегда горизонтальный: ровно шесть граф «Попытка 1…6» и «Лучший результат». Графы «Сек. 1–3» в нём не выводятся.
- Для бега: три графы секундомеров «Сек. 1–3», лист книжный.
- В смешанном общем списке у забега нет единой дистанции. Поэтому `startlist` теперь отдаёт у каждого участника `distance`, `rtype`, `slots` (по заявке), и бланк делится по дисциплинам: бег отдельно, техника отдельно.

## Корзина печати (Регистрация → «Бланки для печати»)
1. Отметить бланки галочками (группа × пол: «все», «только мальчики», «только девочки»).
2. «🛒 Добавить выделенные в корзину печати». В корзине запоминаются группа, пол и вид (по забегам / общим списком), хранится в браузере секретаря.
3. «🖨️ Сформировать единый файл для печати» открывает `/protocol?event=ID&kind=cart`: все бланки одним документом, каждый с новой страницы (`page-break-after: always`). Техника идёт альбомными листами, бег книжными (именованные страницы `@page`).
