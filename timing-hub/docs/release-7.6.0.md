# 7.6.0 — глобальный CSV-корректор (14.10.2026)
- **Выгрузка «Заявки …csv»** (этап «Регистрация»): `ID заявки · Фамилия · Имя · Отчество · Пол · Год рождения · Разряд · Команда / Клуб · Тренер · Дисциплина · Нагрудный номер`, далее справочные колонки (статус, категория, лучший результат, представитель, контакт, подана).
- **«📥 Загрузить и применить изменения из CSV»** → `POST /api/events/<id>/regs-csv` (`Hub.apply_regs_csv`). Сопоставление строго по `registrations.id`. Сначала проверка (`?check=1`): сводка изменений и примеры, подтверждение; затем запись.
  - Перезаписываются: фамилия, имя, отчество, разряд, команда, тренер — в `registrations` и в связанных строках `entries` (имя, команда, тренер, разряд); номера — через `save_bibs` (все или ничего, один человек — один номер на все дисциплины, повтор у разных людей отклоняется).
  - Пустая фамилия/имя — ошибка; пустые отчество, команда, тренер очищают поле; пустой разряд и пустой номер оставляют прежнее значение. Разряд — только из списка (`Б/р … ЗМС`, написание нормализуется). Пол, год рождения, дисциплина и справочные колонки не применяются. Обезличенные заявки пропускаются.
  - Любая ошибка (чужой ID, дубль ID, неизвестный разряд, чужой номер) отменяет весь файл; в журнал аудита пишется сводка.
  - Публичные списки, табло, протоколы и шаг 2 Мастера читают данные из базы — видят исправленное сразу.
- Остаются с 7.5.1: «❌ Очистить отклонённые заявки», сводка на шаге 1 Мастера. Старый маршрут `bibs-csv` (только номера) сохранён.
